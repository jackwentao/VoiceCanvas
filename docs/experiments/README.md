# 实测与回归样本

[项目首页](../../README.md) · [测试指南](../TESTING.md)

这里保留能支持当前项目结论或被自动测试读取的证据。使用者从[使用指南](../使用指南.md)开始即可，无需逐份阅读实验过程。以下均为2026-11-17的研发验证，不是客户研究、稳定成功率或生产性能承诺。

## 当前能力的证据

| 关注点 | 记录 | 可以说明什么 |
| --- | --- | --- |
| 完整故事能否完成独立拆镜 | [自主分镜 Agent](storyboard-agent-20261117/README.md) | 两次真实调用得到3个独立镜头、时长与说明；动作质量仍有失败 |
| 单镜等待为何变长、如何缩短 | [生成延迟对照](drawing-latency-20261117/README.md) | 同供应商小样本关闭思考明显缩短耗时；不能外推平均延迟，旧路由问题随后已被 Agent 替换 |
| 模型能否看图并修正 | [同模型视觉工具](shot-visual-tools-20261117/README.md) | 看图识别有效、工具闭环可用；一次递杯修正仍未达标 |
| 已有文案能否快速调整 | [直接文字编辑](direct-text-edit-20261117/README.md) | API/浏览器无模型改字、预览保存与冲突保护；复杂排版仍有限制 |
