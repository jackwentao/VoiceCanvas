# 首次运行的环境失败

提交 `ce054cc`，使用试点报告所列的模型和参数。前两次任务沿用了旧环境中 `VOICECANVAS_SHOT_LOCAL_ADDRESS=::` 的显式 IPv6 绑定。

| 用例 | 任务状态 | 服务耗时 | 工具调用 | 服务返回 |
| --- | --- | --- | --- | --- |
| VC-01 | failed | 0.808 s | 0 | 任务 Agent 连接失败，当前分镜已保留 |
| VC-02 | failed | 0.319 s | 0 | 任务 Agent 连接失败，当前分镜已保留 |

本机探测模型网关时，IPv4 返回 HTTP 200，IPv6 无法连接。用同一模型和密钥，通过试跑进程环境设 `VOICECANVAS_SHOT_LOCAL_ADDRESS=0.0.0.0` 后，两条用例均得到产物和工具记录。
