# 分镜 Agent 评测试点

本次评测固定同一个模型和配置。以任务为单位报告最终验收、图文必做项、修改与保留项、工具正确性和耗时。画面按能否传达用户指定内容判分，精美程度仅作观察。助手总结保留在证据中。

## 用例与判据

| 用例 | 起点和用户需求 | 最终验收 | 必要操作与约束 |
| --- | --- | --- | --- |
| VC-01 雨天咖啡 | 新项目只有一个空镜头。使用[历史 API 运行](../storyboard-agent-20261117/api-run.json)中的原始请求。三镜各 5 秒，依次入店、递杯、咖啡与字幕特写。 | S1 三份独立可渲染 SVG，顺序为入店、递杯、特写。S2 每镜 5 秒且景别字段均有内容。V1 雨天店外，黄雨衣黑短发女孩有清晰的入店动作，门头可读为「暖杯咖啡」。V2 同样外观的女孩与白衬衫绿围裙店员各自以手接触同一杯咖啡。V3 咖啡为近景主体，字幕「雨天咖啡买一送一」逐字可读。V4 三镜有共同的暖色插画语言，雨景冷色允许作为对比。 | 建立独立镜头并保存时长及景别，给每镜生成画面，核对实际交付。接受任意有效工具顺序和合理的并行绘制。 |
| VC-02 递杯修正 | 导入[原始 SVG](../shot-visual-tools-20261117/before.svg)，设录制时的拍摄说明、景别和 5 秒时长，使用[历史视觉运行](../shot-visual-tools-20261117/agent-run.json)中的原始请求。 | M1 女孩的手贴住杯柄并表达抓握。M2 店员手从下方接触并托住杯底。M3 两人接触同一杯，互相握手不算。P1 保留暖色插画。P2 保留黄雨衣、白衬衫和绿围裙。P3 保留原有文字符号。P4 镜头 ID、顺序与拍摄说明不变。 | 先渲染和看原图，发现关键偏差后尝试一次修正，再看修正版本。最多一次绘图，目标必须绑定当前镜头，不得使用模板覆盖。 |

看图时先按需求和最终 PNG 作判定。VC-02 同时查看起点图核对保留项。必做项用「通过」「失败」「不可判定」记录。任一必做项失败即任务失败。没有失败但存在不可判定项，整条进入复核。对工具调用逐步核对意图、参数与目标、前置条件和副作用。记录工具决策是否正确、执行是否成功及必要操作完成数，区分语义错误的画面与工具执行错误。

## 评测体系适用性与下一次对照

当前系统可以记录两个用例的初始状态、最终状态、目标镜头和版本、工具执行结果、成图及整条服务耗时。稳定的镜头 ID 和版本使「改错对象」「修图未提交」与「保存成功但动作仍错」可分别核对。这次严格通过 **0/2**。两条均 100% 覆盖必要操作，三镜数量、时长和指定字幕通过，局部修正保留项通过。样本各一次，用于发现缺陷和冻结对照方法。

| 目前可定位的问题 | 对应下一轮验证 |
| --- | --- |
| 入店、递杯初稿都能生成，但接触和动作没画清楚 | 固定同一输入及画风，从门槛、手、杯柄和杯底的可见几何关系逐项对照 |
| 合理的修图调用生成了非法 SVG，随后 Agent 再次提出超预算调用 | 分别验证局部补丁的 SVG 合法性、失败后预算识别。检查已有画面是否保留，下一轮调用是否避开已用完的预算 |
| 无法从现有数据拆出决策时间、缓存开销和并行步骤对等待的贡献 | 补记每次决策及工具的起止时刻、并行批次、渲染缓存命中，并分别记录首次落盘与任务结束时刻 |
| 同模型自评在复杂接触上有误判 | 先对固定 PNG 进行独立人工双评，分歧样本保留。待规则稳定后再用人工标签校准视觉 Judge |

后续按一次改动一个假设配对比较。固定用例、模型、参数、浏览器和基准线，每条至少重复三次，保留所有失败。对局部修图改动优先比较 VC-02 的 M1–M3 和保留项，兼查 VC-01 的结构是否回归。若提升只出现在一个随机样本，先继续复跑。只有指标改善且轨迹能印证原假设，才归因到具体改动。关键必做项、保留项或工具约束出现可复现退化时，定位原因或回滚该改动，再跑同一批用例。重复运行和从最终状态验收的做法参考 [τ-bench](https://arxiv.org/abs/2406.12045)。

## 复跑

从仓库的 `backend` 目录运行。读取该目录的模型配置，也可用 `--env-file` 指定已有配置。输出目录须是尚不存在的新目录，脚本会在其中使用独立数据库。每次运行会发起两条真实模型任务。

```powershell
$env:PYTHONPATH = "src"
uv run --frozen --no-editable python evaluation/run_pilot.py --out D:/work/voicecanvas-eval-next
```

现有回归可验证同一套工具执行、SVG 校验、真实预览及版本绑定。实际画面验收由上表逐项复核。

```powershell
uv run --frozen --no-editable pytest -q tests/test_storyboard_agent.py tests/test_shot_visual_tools.py
uv run --frozen --no-editable ruff check evaluation/run_pilot.py
```
