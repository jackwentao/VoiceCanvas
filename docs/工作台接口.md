# 工作台固定业务接口

## 职责

后端拥有项目、镜头、元素、操作历史、撤销重做栈、待澄清任务、Token 用量与长期偏好。
前端只保存后端快照用于展示，以及选中元素、输入草稿、面板开合、网络请求状态等临时 UI 状态。
前端不得合成项目、执行领域命令、解析澄清候选、生成项目 JSON 或用本地数据兜底业务请求。

自然语言仍使用既有编排接口。按钮使用下列固定动作，不依赖 LLM 理解按钮文案。
新增动作应先扩展后端 Pydantic 契约、业务校验与测试，再接页面入口。

## 查询

| 方法与路径 | 结果 |
| --- | --- |
| `GET /api/projects` | `{ projects: [{ id, title, mode }] }`，列出后端保存的项目 |
| `GET /api/projects/{projectId}/workspace` | `{ project, history, events, undoRedo, pending, usage }` |
| `GET /api/render-catalog` | 后端维护的渲染能力目录 |

`undoRedo` 包含 `canUndo`、`canRedo` 与下一步操作说明。页面不自行计算可撤销性。
`pending` 为空或 `{ sessionId, nextAction }`。刷新页面或重启后可用相同会话恢复澄清。
`usage` 包含 `lastTurn`、`total` 和后端计数会话标识；重新打开页面不会丢失累计用量。

## 固定动作

统一提交 `POST /api/projects/{projectId}/actions`，返回完整工作台快照。

| 业务动作 | 请求 JSON |
| --- | --- |
| 切换镜头 | `{ "action": "switch_scene", "sceneId": "scene_1" }` |
| 修改背景 | `{ "action": "set_background", "sceneId": "scene_1", "color": "#abcdef" }` |
| 重命名项目 | `{ "action": "rename_project", "title": "奶茶上新" }` |
| 撤销 | `{ "action": "undo" }` |
| 重做 | `{ "action": "redo" }` |
| 清空项目累计用量 | `{ "action": "reset_usage" }` |

未声明的动作、额外字段和非法字段格式返回 422；不存在的镜头、空白名称、没有
可撤销步骤等业务错误返回 400，且不修改项目。动作不会调用 Planner。

## 继续使用的接口

- 创建：`POST /api/projects`；导入：`POST /api/projects/import`。
- 输入：`POST /api/orchestrations/stream`；澄清：`POST /api/orchestrations/{sessionId}/resume`。
- 导出：`POST /api/projects/{projectId}/export`；JSON 包与文件名由后端生成。
- 素材：`GET /api/assets/catalog`、`GET /api/assets/catalog/raw`，前端不接触桶凭证。
- 偏好：`GET/POST /api/users/{userId}/memories`、`PATCH/DELETE /api/memories/{memoryId}`。

PNG 的范围、目标镜头与文件名由后端确认；浏览器只把后端 SVG 或获准的镜头展示
栅格化成 PNG 并下载。这属于展示层转换，不创建项目包或修改任何后端业务数据。

## 请求与断连语义

SSE 中间事件只展示处理进度，最终结果完成后重新查询完整工作台快照。请求中阻止
重复提交；断流后只查询状态，不自动重放指令。后端离线时显示明确错误并保留最后一次
快照供查看，无法连接时不创建本地项目。恢复服务后点击“重新连接”。
