# 给项目绘图 Agent 加载 skill

`svg-illustration` 已接入单镜头 SVG Agent，默认启用。它不是仅放在 `.codex/skills` 或 `.claude/skills` 的文件：后端会读取随包发布的 `SKILL.md`，按阶段提取适用知识，实际加入发送给绘图模型的 system 消息。

搜索结果不是效果证明。本次下载并阅读前两个 skill 及相关参考文件，保留原文与固定 commit，见 [第三方技能来源](../third_party/drawing-skills/README.md)。未执行上游脚本，未安装新第三方运行依赖。上游原文保持英文，项目改编指令与说明使用中文。

`svg-creator` 的原工作流规定必须多轮渲染和查看 PNG，而且示例脚本有自动安装 CairoSVG 的行为；`vector-illustration` 还使用独立 scene.json 和渲染/评审脚本。当前文本模型接口无法执行这些流程，所以没有把原文全文塞入 system。当前接入是**文字知识适配**，不代表完整实现两套原 skill，也没有让文本模型凭空获得看图或执行脚本能力。

## 实际加载路径

```text
VOICECANVAS_SHOT_DRAWING_SKILL
  → ShotModelConfig.drawing_skill
  → load_drawing_skill（只接受已审阅的内置名称）
  → SKILL.md 的 draw 或 edit 区段
  → compose_drawing_prompt + 原有 SVG/JSON 协议
  → /chat/completions 的 system 消息
```

- 生成：主体与负空间、前后景、语义分组、路径与连接、光源、阴影、适量渐变和滤镜。
- 修改：定位语义对象、保留无关区域、保护共享渐变/滤镜引用、保持唯一的源码替换目标。
- 无新增模型调用，无自动付费重试；画布、完整 SVG、局部修改 JSON 与白名单规则仍由基础协议约束。
- 用户明确风格优先，不强制每张画都使用渐变、高光、八头身、固定调色板或圆头线段人物。
- 模型只能做源码一致性推敲，不能声称已渲染或完成视觉自审。真正的浏览器预览仍由用户审阅。

默认配置：

```dotenv
VOICECANVAS_SHOT_DRAWING_SKILL=svg-illustration
```

关闭，回到上一版基础提示：

```dotenv
VOICECANVAS_SHOT_DRAWING_SKILL=none
```

修改 `backend/.env` 或后端环境变量后重启后端，打开 `http://127.0.0.1:4178/shot.html` 并生成新镜头。已有画面不因开关改变而自动重绘；下一次修改使用当前配置的 edit 知识。未知名称、资源文件缺失或格式错误会明确报错，不静默关闭，也不先发送收费请求。

## 扩展边界

运行资源位于 `backend/src/voicecanvas/adapters/llm/skills/svg_illustration/`，其中 `SKILL.md` 的 `runtime:draw` 与 `runtime:edit` 标记内文本分别进入对应请求，每段最多 4000 字符。NOTICE 和两份许可证同目录发布。原文与 provenance 位于仓库根目录 `third_party/drawing-skills/`，不进入模型上下文。

新增技能时先审阅内容与授权，另建内置目录并在 `drawing_skills.py` 注册名称，再增加阶段路由与失败测试。当前不允许浏览器上传任意 SKILL.md、通过提示词选择文件路径或执行里面的 shell 命令；也没有实现通用 Agent Skills 市场、远程更新或按语义自动挑选多个插件。这个改动只解决绘图 Agent 确实读到受控的作画知识。

原始技能知识归上游作者，模型负责具体绘制，项目原创部分是精简适配、按阶段加载、配置、协议隔离和验证。知识增加会增加输入 token，且不保证画质改善，推理模型仍可能超时、截断或画错；可通过开关对照，用户用撤销保留接受过的版本。

## 测试方式

在 `backend` 下执行：

```powershell
python -m pytest tests/test_drawing_skills.py tests/test_single_shot.py -q
python -m pytest -q
python -m ruff check src/voicecanvas/adapters/llm/drawing_skills.py src/voicecanvas/adapters/llm/svg_shot.py src/voicecanvas/infrastructure/shot_factory.py tests/test_drawing_skills.py
python -m mypy src/voicecanvas/adapters/llm/drawing_skills.py src/voicecanvas/adapters/llm/svg_shot.py src/voicecanvas/infrastructure/shot_factory.py
```

本次离线结果：61 项 skill/单镜头测试通过，全量后端 229 passed、1 skipped。新增测试检查真正发出的 HTTP 请求：生成和编辑只包含相应阶段知识、基础协议不丢失、用户输入与 SVG 原样传递、开关关闭、非法名称、文件缺失/格式错误，以及从不同工作目录加载。它们只证明接入与协议行为，不给审美打分。

另用本机已有 hatchling 缓存构建 wheel，确认 `SKILL.md`、NOTICE 和两份许可证实际进入安装包；在隔离 Python 进程中直接从 wheel 加载成功，生成区段为 836 字符、修改区段为 397 字符。没有为构建下载或安装新依赖。

真实端点验收记录：同一个雨夜镜头先直接连接，再使用本机已配置代理各尝试一次，分别在约 8.17 秒和 7.11 秒连接中断，未得到完整 SVG，也未进入编辑阶段；失败没有写入画面版本。模型用量未知，不能按零计费。这两次失败不足以判断是服务端、路由或本机网络的问题。当前尚无这个 skill 配置下的真实出图样本，不能声称已验证审美收益；上一轮短提示对照的图片也不能当作本次 skill 的产物。
