# VoiceCanvas Demo 脚本与指令能力验收

> 本文档用于锁定比赛 Demo 路径和 MVP 阶段承诺支持的语音指令能力。实现、测试和录屏都应优先覆盖本文档，而不是无限扩展语料范围。

## 当前验收状态

截至 2026-06-14，Demo 主线已经落到当前代码。评审可按根目录 [README](../README.md) 启动前端、后端和可选 MinIO，再按本文档主线验证。

完成情况说明：

- MVP 主线能力以 [指令完成情况](./指令完成情况.md) 为准。
- Demo 视频地址已在 README 顶部标出。
- 当前默认走本地 `DemoCommandPlanner`，保证离线演示稳定；真实 LLM 可通过 `VOICECANVAS_PLANNER=hybrid` 开启。
- 长图导出、七牛云对象存储适配、云端 ASR 和任意复杂生图不作为当前 MVP 过关承诺。

## 目标

VoiceCanvas Demo 需要证明：

- 用户首次点击进入语音创作模式并授权麦克风后，通过持续语音完成核心创作操作。
- 系统把自然语言转成结构化命令，而不是直接生成一张不可编辑图片。
- 每一次写操作都经过命令校验、命令执行、Project State 更新和 Canvas Patch 推送。
- 遇到指代不明确时，系统能进入澄清流程并恢复原任务。
- 最终结果可撤销、可继续编辑、可导出。

## 纯语音控制边界

受浏览器麦克风权限安全策略限制，用户首次进入应用时需要通过一次显式操作授权麦克风。完成授权并进入语音创作模式后，画布创建、元素修改、删除、撤销/重做、澄清选择、清空和导出等核心创作操作均通过语音完成，不要求用户再次使用鼠标或键盘。

Demo 验收以如下问题为准：

```text
从用户说出第一条绘图指令开始，到作品导出结束，用户是否全程没有操作鼠标和键盘？
```

如果答案为“是”，则满足本项目对比赛题目“纯语音控制绘图创作”的实现边界。

## Demo 主线脚本

建议录制 3 到 5 分钟，按以下顺序演示。

| 步骤 | 演示语音 | 预期画面 | 预期技术链路 |
| --- | --- | --- | --- |
| 1 | 创建一个三镜头的珍珠奶茶带货分镜，主打低糖和新品上市 | 生成三张镜头卡片，主画布逐步出现元素 | `EXECUTE_COMMANDS` -> `CREATE_SCENE` / `ADD_ELEMENT` -> `CANVAS_PATCH_APPLIED` |
| 2 | 切换到第二镜头 | 当前画布切到第二镜头，左侧历史区高亮 | `SWITCH_SCENE` -> `ACTIVE_SCENE_CHANGED` |
| 3 | 给第二镜头加一个箭头，指向低糖标签，写上核心卖点 | 商品和低糖标签之间出现箭头 | `ADD_ELEMENT`，元素类型为 `connector` |
| 4 | 把标题改成低糖也好喝 | 标题文字更新 | `UPDATE_ELEMENT` |
| 5 | 把商品放大一点，并移到中间 | 商品尺寸和位置更新 | `UPDATE_ELEMENT` 或 `ARRANGE_LAYOUT` |
| 6 | 把它改成红色 | 如果“它”不明确，右侧 AI 栏询问操作对象 | `ASK_CLARIFICATION` -> `WAITING_FOR_USER` |
| 7 | 改标题 | 原任务恢复，标题颜色变红 | `POST /api/orchestrations/:sessionId/resume` -> `UPDATE_ELEMENT` |
| 8 | 撤销上一步 | 标题颜色恢复 | `UNDO` 或历史逆命令 |
| 9 | 导出项目数据 | 出现 JSON 导出结果或下载提示 | `EXPORT_PROJECT` |
| 10 | 导出当前画面图片 | 出现图片导出结果或下载提示 | `EXPORT_PROJECT`，格式为 `png` |

## 支持级别

- `MVP 必须支持`：Demo 和自动化测试优先覆盖。
- `MVP 降级支持`：必须有稳定兜底，例如未知元素用语义占位。
- `P1 加分支持`：时间允许时实现，不能影响主链路稳定性。

## 指令能力清单

### 1. 创建项目或分镜

支持级别：MVP 必须支持

能力说明：根据用户主题创建自由画布或多镜头分镜，并生成初始结构化元素。

技术动作：

- `EXECUTE_COMMANDS`
- `CREATE_SCENE`
- `ADD_ELEMENT`
- `SWITCH_SCENE`
- `CANVAS_PATCH_APPLIED`

验收语料：

- 创建一个三镜头的珍珠奶茶带货分镜，主打低糖和新品上市。
- 新建一个空白画布，我想先画一张活动海报草图。
- 帮我生成一个蓝牙耳机带货分镜，重点突出降噪和长续航。

### 2. 镜头管理

支持级别：MVP 必须支持

能力说明：通过语音新增、删除、切换镜头，维护 `activeSceneId` 和镜头顺序。

技术动作：

- `CREATE_SCENE`
- `DELETE_SCENE`
- `SWITCH_SCENE`
- `SCENE_CREATED`
- `SCENE_DELETED`
- `ACTIVE_SCENE_CHANGED`

验收语料：

- 切换到第二镜头。
- 在第二镜头后面插入一个镜头。
- 删除最后一个镜头。

### 3. 添加文字和字幕

支持级别：MVP 必须支持

能力说明：在当前镜头或指定镜头添加标题、字幕、说明文字和按钮文案。

技术动作：

- `ADD_ELEMENT`
- `CanvasElement.type = "text"`
- `ELEMENT_ADDED`

验收语料：

- 在顶部加一行标题，写新品上市。
- 给第一镜头加字幕，写今天发现一家宝藏奶茶店。
- 在右下角加一个按钮，写马上下单。

### 4. 添加人物、商品和标签

支持级别：MVP 必须支持

能力说明：添加常见创作元素。MVP 可先用结构化形状、图标或语义占位表达，不强依赖生图模型。

技术动作：

- `ADD_ELEMENT`
- `CanvasElement.type = "shape" | "image" | "unknown"`
- `ELEMENT_ADDED`

验收语料：

- 在第二镜头加一个奶茶产品，放在画面中央。
- 给第三镜头加一个开心的顾客。
- 在商品旁边加一个红色标签，写立减十元。

### 5. 添加箭头和连接线

支持级别：MVP 必须支持

能力说明：表达元素之间的关系，是 VoiceCanvas 区别于普通文生图的重要能力。

技术动作：

- `ADD_ELEMENT`
- `CanvasElement.type = "connector"`
- `ConnectorElement.from`
- `ConnectorElement.to`
- `ELEMENT_ADDED`

验收语料：

- 从奶茶指向低糖标签画一个箭头。
- 在人物和商品之间加一条连接线。
- 给第二镜头加一个箭头，指向核心卖点，线上写低糖新品。

### 6. 修改文字内容

支持级别：MVP 必须支持

能力说明：修改已有文字、字幕、按钮文案、箭头说明或镜头说明。

技术动作：

- `UPDATE_ELEMENT`
- `UPDATE_SCENE`
- `ELEMENT_UPDATED`
- `SCENE_UPDATED`

验收语料：

- 把标题改成低糖也好喝。
- 把按钮文字改成马上下单。
- 把第二镜头说明改成产品特写，突出低糖卖点。

### 7. 修改视觉属性

支持级别：MVP 必须支持

能力说明：修改元素颜色、大小、透明度等基础视觉属性。

技术动作：

- `UPDATE_ELEMENT`
- `ELEMENT_UPDATED`

验收语料：

- 把标题改成红色。
- 把商品放大一点。
- 把优惠标签变小一点。

### 8. 调整位置、布局和图层

支持级别：MVP 必须支持

能力说明：通过自然语言调整元素位置、对齐、排列和层级。

技术动作：

- `UPDATE_ELEMENT`
- `ARRANGE_LAYOUT`
- `ELEMENT_UPDATED`

验收语料：

- 把商品移到中间。
- 让人物和商品左右排列。
- 把标题置顶。

### 9. 删除元素

支持级别：MVP 必须支持

能力说明：删除指定元素或最近添加元素。高风险批量删除需要确认。

技术动作：

- `DELETE_ELEMENT`
- `ELEMENT_DELETED`
- `HistoryEntry`

验收语料：

- 删除标题。
- 把优惠标签删掉。
- 刚才加的箭头不要了。

### 10. 风格调整

支持级别：MVP 必须支持基础风格，P1 扩展更多风格

能力说明：对项目或镜头应用整体风格，MVP 先映射为配色、背景和基础样式调整。

技术动作：

- `UPDATE_PROJECT_STYLE`
- `UPDATE_SCENE`
- `UPDATE_ELEMENT`
- `PROJECT_STYLE_UPDATED`

验收语料：

- 整体改成清爽绿色风格。
- 让第二镜头更像数码产品广告。
- 第三镜头加强促销感，把优惠做得更醒目。

### 11. 澄清、确认和取消

支持级别：MVP 必须支持

能力说明：当目标元素、镜头或导出格式不明确时，系统暂停任务并等待用户回答，回答后恢复原会话。

技术动作：

- `ASK_CLARIFICATION`
- `WAITING_FOR_USER`
- `CLARIFICATION_REQUESTED`
- `POST /api/orchestrations/:sessionId/resume`

验收语料：

- 把它放大一点。
- 删除那个。
- 不是，改第二个。

### 12. 撤销和重做

支持级别：MVP 必须支持撤销，重做尽量支持

能力说明：根据历史记录回退或恢复最近的命令结果。

技术动作：

- `HistoryEntry.inverseCommand`
- `UndoRedoState`
- `CANVAS_PATCH_APPLIED`

验收语料：

- 撤销上一步。
- 刚才那个不要了。
- 重做刚才那一步。

### 13. 清空和重新开始

支持级别：MVP 降级支持

能力说明：清空当前镜头或重新开始属于高风险操作，必须先确认。

技术动作：

- `ASK_CLARIFICATION`
- `CLEAR_SCENE`
- `DELETE_ELEMENT`
- `ELEMENT_DELETED`
- 用户说“确认清空”后才执行 `CLEAR_SCENE`，说“取消”或“不清空”时不修改 Project。

验收语料：

- 清空当前镜头。
- 删除所有元素。
- 重新开始这个画布。

### 17. 环境噪声过滤

支持级别：MVP 必须支持

能力说明：持续监听过程中，明显环境噪声、咳嗽声、无意义填充词不能进入后端指令系统，避免误触发绘图或高风险操作。

技术动作：

- 前端 `VoiceSessionController` 在最终转写进入 Orchestrator 前执行噪声过滤。
- 命中噪声后只更新本地状态，不调用 `/api/orchestrations` 或 `/resume`。

验收语料：

- 嗯。
- 咳嗽。
- 环境噪声。
- 背景噪声。

### 14. 导出

支持级别：MVP 必须支持 JSON 和当前画面图片，P1 支持分镜长图

能力说明：把项目结构或当前画面导出，便于提交、分享和复盘。

技术动作：

- `EXPORT_PROJECT`
- `EXPORT_COMPLETED`
- `TurnSummary`

验收语料：

- 导出项目数据。
- 把当前画面导出成图片。
- 把所有镜头合成一张分镜长图。

### 15. 未知元素降级

支持级别：MVP 降级支持

能力说明：用户要求添加系统暂不支持的对象时，不阻断任务，先创建 `unknown` 语义占位元素。

技术动作：

- `ADD_ELEMENT`
- `CanvasElement.type = "unknown"`
- `UnknownElement.reason`
- `ELEMENT_ADDED`

验收语料：

- 在右边放一个复古麦克风。
- 画一个桌子后面有一只恐龙。
- 加一个月球基地的占位图。

### 16. 用户偏好记忆

支持级别：P1 加分支持

能力说明：保存用户明确表达或高置信度重复行为形成的偏好，并在后续创作时作为上下文建议。

技术动作：

- `MemoryExtractor`
- `MemoryRepository`
- `UserMemoryContext`
- 低置信度候选记忆进入确认流程

验收语料：

- 以后我做带货分镜都默认用清爽绿色风格。
- 记住，第一个镜头我习惯叫主图。
- 以后太阳都默认放在左上角。

## 自动化测试建议

后端建议建立 `tests/test_voice_command_capabilities.py`，用 Mock Orchestrator 覆盖：

- 每类 MVP 必须支持能力至少 1 条核心语料。
- 语料能转成合法 `AIAction` 或澄清动作。
- 写操作命令能通过 `CommandValidator`。
- 执行后 Project、Patch、History 三者一致。
- 不明确语料进入 `WAITING_FOR_USER`。
- 未知元素不会失败，而是生成 `unknown` 占位。

前端建议扩展原型契约测试：

- Demo 快捷指令包含主线脚本中的关键语料。
- AI 交互栏能展示澄清问题和本轮总结。
- 画布能渲染 text、shape、connector、unknown。
- 历史区能展示镜头切换、元素新增、元素修改、撤销状态。

## 不承诺范围

以下能力不作为 MVP 过关承诺：

- 任意复杂图像生成质量。
- PS/Figma 级精细图层编辑。
- 多人协作。
- 无限步 AI 自动规划。
- 所有中文口语变体 100% 覆盖。
- 对无法落成结构化元素的内容进行真实绘画。

这些内容可以作为后续扩展方向，但不能影响本次比赛主链路稳定性。
