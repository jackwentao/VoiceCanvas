# 镜头视觉工具

`render_shot` 和 `review_shot` 是 Agent 可选用的能力，没有固定「先生成→渲染→评审→重画」工作流。Agent 根据用户需求和工具返回自行决定是否调用、顺序与是否修正。已有简单管理和直接改画仍可直接执行。

## 两个工具的实际作用

`render_shot({shotId})` 用服务端 Edge/Chromium 把当前合法 SVG 渲染为1280×720 PNG。工具结果包含稳定镜头 ID、画面版本、SVG SHA256、图片 ID 和只读 `previewUrl`。下一次 Agent 决策实际收到这张 PNG 的 `image_url`，而不是只读源码。图片只附在下一次决策消息中；持久化任务不保存 Base64。

`review_shot({shotId, focus?})` 直接获取当前版本的真实 PNG，并让与创作 Agent **同一个模型实例和配置**进行图片评审。本次只用 `deepseek/deepseek-v4.1-flash`，没有第二个模型或供应商。无需先显式 render；若有缓存就直接复用。评审请求只包含拍摄要求、共同设定、检查重点与图片，不提供 SVG 源码。返回可观察事实、最多三个偏差和不确定项，不把 JSON 合法或保存成功视作画质通过。

模型输入使用 Chat Completions 的 `image_url`，默认继续 `reasoning_effort=off`，评审输出预算1800 token、超时90秒、无自动重试。模型不支持图片、请求失败、截断或空回复均明确报错，保留画面。每任务最多四次专门评审、每镜两次；完全相同的图片和要求复用本任务已有评审。绘图预算仍单独限制，没有隐式反复修图。

## 版本和用户界面

缓存身份包括项目、镜头、画面版本、源码摘要和渲染器标识。渲染及评审结束后再次核对画面版本，防止其他页面更新后把旧图说成当前图。

只读 `GET /api/storyboards/{boardId}/shots/{shotId}/previews/{imageId}.png` 返回 PNG；请求必须对应当前项目、镜头和当前版本的既有缓存。GET 不会启动渲染浏览器或请求模型，过期图片返回409。

创作助手新增可展开的「画面预览与评审记录」，展示真实 PNG、对应版本和评审原文。改画后旧诊断标为历史，不加载过期预览，更不会将其套用到新图。Agent 工具进展显示「渲染真实预览」「看图检查」。

## 运行依赖

使用现有 httpx、FastAPI、Pydantic、Python 标准库和服务端已安装的 Edge/Chromium，没有新增 Python/npm 包。可用 `VOICECANVAS_RENDER_BROWSER_PATH` 指定浏览器可执行文件。Windows 自动发现系统 Edge；Linux 查找 chromium/chromium-browser/google-chrome。产品不下载浏览器，不安装软件，不使用用户日常浏览器配置，也不关闭浏览器沙箱。

PNG 缓存和独立临时 profile 放在 `VOICECANVAS_SHOT_DB_PATH` 同级的 `shot-previews/`，数据库放 D 盘时渲染文件也在 D 盘。渲染25秒超时并结束进程树，SVG 先通过现有自包含白名单校验，渲染页面禁用脚本与外部资源请求。图片最大8 MB。

当前基础 Docker 镜像没有预装 Chromium，部署要提供浏览器并以支持沙箱的普通用户运行。未提供浏览器时视觉工具明确失败，已有绘图与管理仍可使用。不会降级为源码评审冒充看图。浏览器版本和字体可能影响最终像素，验收时应使用目标部署环境。

缓存是派生产物，可在服务停止时清理 `shot-previews/`；需要时由工具重新渲染。当前无自动磁盘淘汰策略，长期部署需按存储容量清理缓存。模型仍可能看错，也不能从一张静态图证明整个动作或未提供参考图的跨镜一致性。
