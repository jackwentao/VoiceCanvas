# 首页画廊接口

首页为只读展示入口，与用户工作台的数据生命周期独立。作品信息及 SVG 文件由后端维护，
前端不内置样例业务数据，不在浏览器保存项目。

## 获取画廊

`GET /api/showcase` 返回 `categories`、`items` 和 `total`。
可选参数 `category` 使用服务端返回的分类 ID；未知分类返回 404。
`items` 包含稳定 ID、标题、分类、描述、批注及 `imageUrl`，部分条目包含首屏展示位置 `hero`。

```powershell
Invoke-RestMethod http://127.0.0.1:8000/api/showcase
Invoke-RestMethod 'http://127.0.0.1:8000/api/showcase?category=story'
```

## 获取作品

`GET /api/showcase/{artwork_id}/artwork` 返回 `image/svg+xml`，缓存一小时。
作品 ID 必须匹配服务器目录白名单，不允许输入路径或读取任意文件；未知 ID 返回 404。
SVG 位于 `backend/src/voicecanvas/resources/showcase/`，后端镜像随源码包含资源，
无需 MinIO、外部 LLM 或前端目录。展示画是原创静态样例，不是用户创建的可编辑项目。

## 进入创作

首页“开始我的创作”调用既有 `POST /api/projects`，成功后使用后端项目 ID
跳转到 `workspace.html?projectId=...`。请求期间防止重复提交，失败时保留页面并允许重试。
“进入工作台”只导航，继续由工作台通过后端读取已有项目。
