# 技术选型与依赖声明

[项目首页](../README.md) · [架构说明](ARCHITECTURE.md) · [测试指南](TESTING.md)

本文件说明当前实际使用的能力与边界。版本以 `backend/uv.lock`、`backend/pyproject.toml`、`frontend/package-lock.json` 和 `frontend/package.json` 为准；新增或调整依赖时同步更新本文件。

## 当前产品运行依赖

| 依赖 | 用途与接入位置 | 不可用时与验证方式 |
| --- | --- | --- |
| Python 3.11+、FastAPI、Uvicorn | 后端 API、任务入口及线程池运行 | 启动与 `/health`；路由回归测试 |
| Pydantic v2 | 分镜、画面、任务与工具参数校验 | 无效字段明确拒绝；领域/API 测试 |
| httpx | 后端适配器访问外部模型 | 明确错误、保留画面、不自动付费重试；MockTransport 测试 |
| python-dotenv | 加载本机 `.env` | 进程环境也可配置；密钥不传浏览器 |
| Python 标准库 sqlite3、ElementTree、pathlib、concurrent.futures | 原子持久化、SVG 解析、缓存、后台与并发绘图 | 临时 SQLite、版本/安全/中断回归 |
| Node.js 20+ 内置 http/fs/path | 静态前端和 Node 测试 | `npm run prototype`、`npm test`，无需 npm 安装 |
| 浏览器 Blob、Image、Canvas、Fetch | SVG 预览、PNG/SVG 导出及 API 请求 | 客户端回归和浏览器验收 |
| Web Speech API、SpeechSynthesis | 使用者浏览器的语音识别与播报，可能依赖联网服务 | 不支持或拒绝权限时改用文字；自动测试模拟边界，真人语音现场验收 |
| 服务端已有 Chromium/Edge | 独立进程把合法 SVG 渲染为真实 PNG | 未安装则视觉工具报错，基本绘图/管理保留；资源和版本回归、实际渲染验收 |
| 外部 DeepSeek / OpenAI-compatible Chat Completions | 同一模型负责工具决策、SVG 创作、源码修改和图片评审；当前验证 `deepseek/deepseek-v4.1-flash`，端点 `api.commandcode.ai/provider/v1` | 失败保留已有结果；工具调用、图片输入与截断回归，另做真实在线验收 |

语音并非自研 ASR，浏览器并非自研字体或栅格引擎，模型绘图和图片理解并非自研模型能力。图片服务、任务和状态边界由项目实现，不能用 HTTP 成功代替模型输出质量证明。

## 作画知识来源与加载

默认内置 `svg-illustration` 精简改编自以下固定版本，不执行上游脚本：

| 来源 | 许可 | 采用内容 |
| --- | --- | --- |
| [upbrew-tech/svg-creator-skill](https://github.com/upbrew-tech/svg-creator-skill/tree/1eb83d602a992b69a1771c4e0116a9f7de6ffaa2) | Apache-2.0 | 主体、光影、分层和形体连接知识 |
| [syi0808/svg-skills](https://github.com/syi0808/svg-skills/tree/c5937c2bed48aff98c12cda43ccba2ed6f2880f0/vector-illustration) | MIT，Copyright (c) 2026 Yein Sung | 曲线、接缝、负空间、语义分组与局部编辑 |

固定来源、选取文件哈希、原文和许可证保存在 [third_party/drawing-skills](../third_party/drawing-skills/README.md)。原文是审阅快照，部分链接指向未收录的上游文档，不是本项目运行入口。运行改编文件位于 `backend/src/voicecanvas/adapters/llm/skills/svg_illustration/`，其中 NOTICE 和两份许可证随 Python 包发布。

`drawing_skills.py` 通过 `importlib.resources` 读取已注册内置名称，分别提取 `runtime:draw` 或 `runtime:edit` 区段并加入模型 system 消息，每段最多4000字符。未知名称、文件缺失或格式损坏明确失败，不静默关闭。`VOICECANVAS_SHOT_DRAWING_SKILL=none` 可停用；不接受用户上传任意 skill 或执行其中 shell 命令。

这是作画知识适配，没有完整实现上游 skill 工作流。当前图片工具由项目独立实现，是否调用仍由 Agent 决定；加载知识不保证画质改善。`tests/test_drawing_skills.py` 验证实际请求中的分阶段知识、开关、协议保留与资源加载。

## 已声明但不在当前创作主链路的依赖

| 位置 | 依赖 | 实际范围 |
| --- | --- | --- |
| 后端 | langgraph、langchain-core | 历史结构化 Planner/编排模块；当前自由 SVG Agent 使用应用服务工具循环 |
| 后端 | minio | 历史素材桶适配和初始化脚本；当前自由 SVG、画廊与图片评审无需素材桶 |
| 前端 | express、cors、zod | 包清单仍保留，当前静态启动脚本不导入这些包 |
| 前端开发依赖 | typescript、tsx、vitest、supertest 及相关 `@types/*` | 历史工具准备项；当前 `npm test` 使用 Node 原生测试 |

七牛云 SDK、专用 ASR SDK、React/Vite、独立图片生成服务、生产任务队列均未接入当前产品。本轮仅整理文档，不调整包清单或删除历史代码。

历史 MinIO 初始化脚本使用 Google Noto Emoji PNG，Apache-2.0；来源元信息见 `backend/src/voicecanvas/infrastructure/real_catalog_assets.py`。它们不属于当前自由 SVG 的生成素材。

## 开发与验收工具

pytest、pytest-asyncio、respx、Ruff、mypy 位于后端开发依赖。可选浏览器测试使用部署者已有的 Playwright 与 Chromium/Edge，项目不自动下载；历史实验中的 sharp 只用于离线图片对比，不进入产品运行链路。具体命令见[测试指南](TESTING.md)。

## 项目自研范围

项目实现分镜及镜头领域、工具协议与预算、可信 SVG/文字修改、原子保存与版本冲突、独立历史、任务恢复、版本绑定图片缓存、前端语音编排与下载闭环。模型提供内容与判断，第三方技能提供部分作画知识，浏览器提供语音和像素渲染；实测证据见[验证索引](experiments/README.md)。
