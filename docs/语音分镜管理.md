# 用语音管理自由绘制分镜

`shot.html` 在原有自由 SVG 镜头之上增加项目与镜头列表。每个镜头独立生成、改画、直接改字和撤销重做；分镜层负责名字、顺序、当前选择和结构历史。没有新增绘图模板或限制 SVG 元素集合。

## 启动和使用

沿用根 README 的后端、前端启动命令和模型配置，访问 `http://127.0.0.1:4178/shot.html`。无需安装新依赖。可先不配置模型测试新增、切换、命名与排序；真实绘图仍需后端已有 `VOICECANVAS_SHOT_LLM_*` 配置。

点击“开启语音管理”，允许麦克风，提示音后说一条指令。最终转写自动执行；执行和播报期间暂停识别，完成后恢复监听。说“关闭麦克风”或“结束创作”，也可点击“结束语音管理”。请等待执行完成后再说下一条。输入框执行同一组指令；旁边的“语音输入”只负责听写。

| 目的 | 可说的示例 |
| --- | --- |
| 新项目 | 新建分镜项目 / 项目改名为雨夜归途 |
| 新镜头 | 新建两个镜头 / 新建一个镜头叫开场 |
| 新建并画 | 新建一个镜头，画雨夜便利店门口 |
| 切换 | 切换到第二个镜头 / 下一个镜头 / 上一个镜头 |
| 改名 | 当前镜头改名为妈妈的消息 / 把第二个镜头命名为相遇 |
| 排序 | 把第三个镜头移到第一位 / 第二个镜头前移一位 |
| 复制 | 复制当前镜头 / 复制第二个镜头 |
| 删除 | 删除第二个镜头 → 确认删除；也可说取消 |
| 恢复结构 | 撤销分镜操作 / 重做分镜操作 |
| 查看 | 查看分镜 |
| 绘图或修改 | 画一个手机特写 / 把招牌改成夜归便利店 / 第二个镜头画一个拿伞的女孩 |
| 撤销画面 | 撤销 / 重做 |
| 导出 | 导出SVG / 导出当前镜头（PNG） |

新项目已有一个空镜头，“新建两个镜头”会再加两个，总数变成三个。每次新增 1–12 个，每项目最多 40 个。复制当前已保存画面，不共享后续修改，不复制原镜头全部历史。项目下拉选择最近 50 个项目；更早项目可通过保存的 URL 打开。

管理使用确定性中文命令路由，当前支持上表句式及常见变体；不能保证任意口语或一句多操作均能理解，复合管理命令需要分开说。画面描述继续交给绘图 Agent 自由生成，管理规则不限制画法。

## 保存与误操作恢复

画面存入既有 SQLite，分镜元数据与新镜头在同一事务提交。URL 的 `board` 参数和浏览器本地记录用于恢复项目，`board` 优先于 `shot`；刷新不会自动重新生成画面。旧单镜头 URL 会复制到新项目，原文档独立保留。服务端数据库必须保留，浏览器记录不是数据备份。

删除先展示并播报镜头编号与名称，待确认绑定项目、镜头 ID 和版本。执行其他操作会取消原确认，避免误删切换后的镜头。至少保留一个镜头；删除可以通过“撤销分镜操作”恢复原画面。结构保留最近 100 个快照，不物理清理画面；没有删除整个项目或垃圾回收功能。

“撤销”针对当前画面，“撤销分镜操作”针对新增、删除、排序或命名。切换镜头不消耗结构撤销历史。多页面更新产生冲突时同步最新状态并提示，不自动重试绘图。文字草稿尚未应用时阻止切换与指令执行，可先保存或关闭编辑面板。

不包含自动把长故事拆成全部镜头、跨镜头角色一致性、整组分镜导出或声音转文字自研服务。本期完成的是多镜头创作与语音编排闭环。

## 测试与依赖边界

Web Speech API 由浏览器提供，建议使用支持中文识别的 Chrome / Edge，通过 localhost 或 HTTPS 访问，可能依赖联网服务。权限拒绝或设备不可用会停止会话，可改用文字输入。下载也受浏览器下载设置影响。没有新增包、外部 ASR SDK 或模型付费重试。

```powershell
cd backend
python -m pytest tests/test_storyboards.py -q
# 全量后端
python -m pytest -q
cd ../frontend
npm test
```

手动验收：新项目 → 连续语音新建两个镜头 → 切换第一个并画初稿 → 切换第二个并画初稿 → 复制 → 排序 → 删除确认/取消 → 撤销结构 → 改字保存 → 刷新 → 导出。另用两个标签打开同一项目，先在一页新增，再从旧页排序，应提示冲突并同步，不重复新增或绘图。

自动测试覆盖独立历史、原子保存、旧镜头迁移、确认目标、冲突同步、最终转写执行及恢复监听、权限拒绝和语音导出分发。浏览器验收记录见 [分镜语音验收](experiments/voice-storyboards-20261117/README.md)：API/数据库/下载真实执行，绘图使用已有响应回放、语音使用最终转写模拟；真实麦克风中文识别需要现场验收。
