# 单镜头自由 SVG 创作

当前产品前端统一使用 main 的 `workspace.html` 手绘纸张工作台，`shot.html` 会保留查询参数跳转。本文绘图 API 与文字编辑协议保持适用；输入框旁的麦克风自动执行最终转写，导出在顶部菜单。适配入口与验证见 [main 工作台分镜适配](main工作台分镜适配.md)。

目标是先完成一个镜头的创作闭环：用户描述 → 模型直接绘制完整 SVG → 浏览器预览 → 用户提出修改 → 源码局部替换 → 撤销、重做、导出。入口为 `frontend/src/prototype/shot.html`，旧版结构化分镜入口为 `index.html`。

此入口现已加入 [语音分镜管理](语音分镜管理.md)：项目包含多个独立的自由 SVG 镜头，下述绘图与文字编辑能力应用于当前镜头。旧 `?shot=…` 地址会复制原镜头及历史到新项目，随后通过 `board` 参数恢复；原镜头文档不受修改。

初次绘制提示现增加简短的主体、动作轮廓、面部和接触关系优先级。两场景六次真实对照的请求、全部结果与失败样本见 [人物与动作提示实验](experiments/subject-quality-20261117/README.md)。这项改动仅有小样本支持，尚未解决人物肢体连接或稳定画质问题。

## 运行与验收

依赖与安装沿用根 README，不新增第三方包。后端使用 Python 3.11+ 和现有 `httpx`、FastAPI、Pydantic；前端静态服务只依赖 Node.js 20+ 自带模块。

在 `backend` 下复制 `.env.example` 为 `.env`，填入自己的 API 密钥，然后启动：

```powershell
cd backend
$env:PYTHONPATH="src"
uv run --no-editable uvicorn voicecanvas.api.main:app --port 8000
```

另开终端运行前端（本入口无需先执行 npm install）：

```powershell
cd frontend
npm run prototype
```

访问 `http://127.0.0.1:4178/shot.html`；不同后端端口可以通过 `?apiBaseUrl=http://127.0.0.1:8001` 指定。密钥只存在后端环境变量或本机 `.env`，浏览器不持有密钥。

手动验收：

1. 描述“雨夜便利店门口，穿黄色雨衣的女孩蹲下，把纸箱里的小猫抱起；暖光从门内照出，中景插画”，点击生成，等待完整画面。
2. 输入“只把黄色雨衣改成红色，其他区域保持不变”，检查修改范围。
3. 撤销、重做，再刷新页面，检查当前版本和记录恢复。新建镜头保留旧镜头，旧 URL 中的 `shot` 参数可以再次打开。
4. 导出 SVG 和 1280×720 PNG，确认和当前预览一致。
5. 用两个标签打开同一镜头，在一页提交旧版本请求；应看到版本冲突且同步最新画面，不应自动重试模型。
6. 设置错误密钥后重启后端，再提出修改；失败应保留之前的画面、记录和输入。修正配置后重启后端再试。

语音输入复用现有 Web Speech API 适配器。“开启语音管理”会连续执行最终转写、播报并恢复监听；输入框旁的听写按钮只填入文字，由用户检查后提交。浏览器可能依赖联网语音服务；不支持或拒绝麦克风时可以直接打字。真实麦克风识别仍需在用户浏览器现场验收。

## 配置

| 环境变量 | 默认值 / 用途 |
| --- | --- |
| `VOICECANVAS_SHOT_LLM_BASE_URL` | 回退到 `VOICECANVAS_LLM_BASE_URL`；填写包含 `/v1` 的兼容端点 |
| `VOICECANVAS_SHOT_LLM_MODEL` | 回退到 `VOICECANVAS_LLM_MODEL`；当前验证目标为 `deepseek/deepseek-v4.1-flash` |
| `VOICECANVAS_SHOT_LLM_API_KEY` | 回退到 `VOICECANVAS_LLM_API_KEY`；只在后端使用 |
| `VOICECANVAS_SHOT_MAX_TOKENS` | 32768，范围 1024–65536；包含供应商计入预算的推理 token |
| `VOICECANVAS_SHOT_TIMEOUT_SECONDS` | 300，范围 1–600 秒 |
| `VOICECANVAS_SHOT_DRAWING_SKILL` | `svg-illustration`，加载按阶段改编的作画知识；`none` 关闭，见 [绘图技能接入](绘图技能接入.md) |
| `VOICECANVAS_SHOT_DB_PATH` | 和旧项目数据库同目录的 `svg-shots.sqlite3` |

模型配置在第一次访问单镜头 API 时初始化；修改环境变量需重启后端。每次自然语言生成或修改调用一次模型，无自动付费重试，也不回退为预设图形；“编辑文字”走确定性接口，不调用模型。失败保留上一版文档。关闭页面不保证终止后端正在执行的模型调用；可重新打开同一镜头确认结果后再决定是否提交。

## 直接文字编辑

已有镜头中含文字时，点击预览下方“编辑文字”，选择需要调整的对白、字幕、招牌或消息。可以改内容、字号和换行宽度；输入时即时预览，点击“应用改字”后保存为一个独立版本，支持撤销、重做、刷新恢复与导出。还原预览或关闭面板会放弃尚未应用的草稿；草稿状态下暂停导出，防止导出内容与眼前预览不一致。

排版使用浏览器实际 SVG 字体测量，保留原字体、文字锚点与变换，支持中文标点避让、显式换行及普通多行段落。相邻同样式、同锚点的连续无 id 文本行会合为一个可编辑文字块，例如上一实验中分成两个 text 元素的对白；不会把不同字号的联系人和时间合并。段落改动只更新选中文字，保留气泡、背景、人物与无关文字。

字号提示按当前预览宽度和文字变换计算：小于约 12 显示像素时提醒阅读偏小，“按预览放大字号”尝试达到约 14 像素且不缩小原字号。提示不是强制统一字号；声效、镜头角标等可按需要保持较小。字号上限 160，极小画面或大幅缩小的文字不保证能达到推荐值。

预览检查文字包围盒：超出画布、超出识别出的矩形气泡/底板、与其他文字明显重叠时禁用“应用改字”。没有自动扩大气泡或移动人物；长句放不下时应缩短、调整字号/宽度，或先用自然语言扩大气泡。只识别同级、尺寸合理且包住原文字的矩形底板，不能保证识别任意路径气泡、蒙版和复杂裁剪，也不自动判断是否遮挡人物的脸。应用前仍应看图确认。

共享定义/被引用对象中的文字、特殊字符定位、固定 textLength 字距和混合样式 tspan 暂不直接扁平化，列表会说明原因，可继续使用原自然语言修改。当前是从列表选择文字，不支持在画面上拖动文字或自由拉伸气泡。跨系统字体回退仍可能改变宽度，保存与导出应在实际使用环境检查。

操作不需要新增模型调用或配置新服务。当前文档必须已有可编辑 SVG；生成初稿和调整气泡等绘制操作仍依赖原模型配置。

手动验收：

1. 打开含两行对白的镜头，确认列表以一个文字块显示，改成较长对白，观察即时换行与预览；尚未应用时不应导出旧文档。
2. 应用后撤销、重做、刷新，再导出 SVG/PNG，确认文案与当前画面一致。
3. 在较窄窗口检查手机消息的字号提示，尝试放大；如超出原气泡，应明确提示并禁用保存，原始版本不变。
4. 两个标签页打开同一镜头，先在一页保存，再从旧页面应用文字；应返回 409、同步最新文档且不自动重试。

自动测试（backend）：`python -m pytest tests/test_shot_text_edit.py tests/test_single_shot.py -q`。前端执行 `npm test`，包括文字换行、组合字符、可读性、变换与客户端版本传递。完整本机浏览器验收记录见 [直接改字验收](experiments/direct-text-edit-20261117/README.md)。

## 分层边界

```text
shot.html / shot.js → ShotClient → /api/shots
  → ShotService → ShotGenerator 协议 → OpenAICompatibleShotGenerator → 外部模型
                → ShotRepository 协议 → SQLiteShotRepository
  → validate_svg / apply_source_edits → 可信 SVG 源文档
```

- 领域层保存完整 SVG，不转换成旧 `CanvasElement` 列表，不限制主体类别。自由 path、渐变、裁剪、蒙版、滤镜和语义分组可直接保留。当前画布固定为 1280×720。
- 初次生成要求完整 SVG；修改要求 `{"edits":[{"old":"唯一原文","new":"替换内容"}]}`。每个替换必须唯一匹配，最多 20 处；全部成功且最终 SVG 校验通过后才保存，不写入半成品。
- XML 白名单校验拒绝脚本、事件属性、外链、DTD、嵌入 HTML、外部图片与不支持的 CSS。预览使用 Blob URL 和 `<img>`；文字编辑时仅将已经过此校验的 SVG 放入不可见 iframe 测量区，测量字体宽度和坐标。测量页通过 sandbox 禁止脚本，并通过 CSP 禁止外部资源。用户输入作为文本节点写入，不解释为 HTML/SVG 标记。导出仍为自包含 SVG。
- 直接编辑的领域函数只接受当前版本的文字索引、文本行、字号、行距和基线，不接受整个候选 SVG。服务端重建目标文字块并再次校验，不允许借改字请求修改人物或背景。浏览器测量负责显示效果，领域层不依赖浏览器或字体引擎。
- 每次成功提交保存不可变的 SVG 快照，最多 40 个版本；撤销后修改会截断重做分支。`version` 是独立递增的并发版本，不能用历史游标代替。
- SQLite 使用原子条件更新，防止长模型调用覆盖另一页面已提交的修改或撤销。
- 该流程不依赖旧 Planner、Render Catalog 或 LangGraph 编排；旧接口与演示路径仍可单独使用。

画面内容及审美主要来自外部模型的 SVG 编码能力。项目原创部分是生成与源码修改协议、校验与原子提交、版本控制、持久化、预览和导出闭环。当前不包含视觉模型看图自审，不声称能自动识别人物肢体或遮挡错误；局部修改的语义范围由模型遵循指令，源码检查只能保证替换有效和格式安全。模型仍可能画错、改多或输出截断，需要用户审阅、撤销和继续描述。

## API

| 方法与路径 | 输入 / 行为 |
| --- | --- |
| `POST /api/shots` | `{"title":"未命名镜头"}` → 新建空白镜头 |
| `GET /api/shots/{id}` | 当前 SVG、文字块 texts、版本、历史元信息、可撤销/重做标志 |
| `POST /api/shots/{id}/generate` | `{"expectedVersion":0,"instruction":"描述或修改"}` |
| `POST /api/shots/{id}/text` | `{"expectedVersion":1,"index":0,"lines":["第一行","第二行"],"fontSize":28,"lineHeight":1.35,"y":120}` → 确定性文字修改，无模型调用 |
| `POST /api/shots/{id}/undo`、`redo` | `{"expectedVersion":1}` |
| `GET /api/shots/{id}/export.svg` | 下载当前 SVG；空白文档返回 409 |

生成及历史操作返回完整当前状态。历史元信息包含指令、时间、模型和用量，不重复返回所有历史 SVG。404 表示镜头不存在，409 表示版本冲突，422 表示输入或 SVG 校验失败，502 表示外部模型失败。失败请求不生成新历史版本。该 MVP 沿用本地开发 API，尚无用户鉴权或多人项目权限。

文字修改同样返回完整状态。`texts` 含当前版本内的首个文字索引 index、组成行的 indices、text、editable 和 reason；索引只对当前版本有效，必须携带 expectedVersion。每次最多 2000 字、100 行，字号 8–160、行高倍数 1–3，坐标为 SVG 内部基线。前端测量生成布局参数；服务端验证结构与取值，不把客户端提供的布局当作视觉质量证明。此类历史记录的 model 为 null、usage 为空。
