# 创作工作台使用与验收

## 启动

按项目 README 启动后端与前端，打开 `http://127.0.0.1:4178/index.html` 手绘首页，
点击“开始我的创作”，或直接访问 `http://127.0.0.1:4178/workspace.html`。
前端需要后端在线；使用 `?apiBaseUrl=http://127.0.0.1:8001` 可指定独立后端。
地址中的 `projectId` 只定位后端项目，不存储项目内容。

## 使用

1. 左侧新建项目或选择已有项目；空白画布内的示例只填入草稿，点击发送开始执行。
2. 输入框支持 Enter 发送、Shift+Enter 换行；点击麦克风或 Alt+V 开启/停止持续语音。
3. 点击左侧镜头缩略图切换；点击画布元素查看名称；修改内容继续使用语音或文字。
4. 助手展示结果。澄清时候选元素被标记，可点击候选按钮或直接回答；刷新后继续恢复。
5. 工具栏修改背景，Ctrl+Z 撤销、Ctrl+Shift+Z 重做；可在左侧展开操作历史。
6. 顶部导出 PNG 或可编辑 JSON；左下角载入 JSON，后端校验后恢复项目。
7. 顶部创作偏好支持新增、编辑、启停、删除，所有变更经后端接口保存。
8. 助手可收起；小屏默认收起，窄屏提供横向镜头列表，画布始终保持作品比例。

## 自动验证

```powershell
npm --prefix frontend run test:prototype
cd backend
uv run --no-editable pytest
uv run --no-editable ruff check .
uv run --no-editable mypy src
```

## 手动验收

- 首页展示六幅原创样例；切换“手绘海报 / 分镜故事 / 灵感草图”，核对后端分类结果。
- 点击作品放大，使用 Escape 或关闭按钮返回；创建画布成功后才进入工作台。
- 工作台点击品牌返回首页；旧 `index.html?projectId=...` 链接仍进入对应工作台。

- 创建三镜头奶茶分镜，切换镜头并修改标题，查看画布与缩略图是否同步。
- 修改背景、撤销、重做，刷新页面和重启后端后验证项目和历史仍然存在。
- 发出含糊指令或清空指令，刷新待确认页面，选择后端提供的候选恢复任务。
- 导出 PNG，检查文件尺寸、文字与素材；导出 JSON 再载入并继续修改。
- 请求处理中连续点击或发送，确保没有重复执行；麦克风停止按钮始终可用。
- 停止后端后发送请求，页面应明确报错，画布不生成本地假结果。重启并重新连接后恢复。
- 检查 1280 像素桌面和 390 像素窄屏，无页面横向溢出；键盘能够操作菜单和弹窗。
- 真实麦克风依赖浏览器支持和用户授权；自动测试覆盖监听/播报恢复，但不代替设备验收。
