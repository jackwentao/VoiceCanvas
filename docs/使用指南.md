# 使用指南

[项目首页](../README.md) · [安装与配置](DEPLOYMENT.md)

## 完成一次分镜创作

1. 打开首页，点击“开始我的创作”，系统创建一个含空镜头的项目。
2. 在底部输入框描述故事、镜头数量、总时长、关键动作和必须出现的文字，按 Enter 发送；Shift+Enter 换行。
3. 等待 Agent 执行。左侧逐镜出现已保存画面，右侧创作助手显示进展、结果和未完成项。
4. 选择镜头继续提出修改，或通过“编辑文字”调整已有文案。
5. 看图确认，再从顶部导出 PNG/SVG；也可以请求“按当前顺序导出全部镜头的 SVG”。多文件下载可能需要浏览器允许。

例子：

> 做一个15秒三镜头分镜：雨夜女孩走进便利店，手机收到妈妈消息，最后女孩撑伞离开。女孩黑色短发、黄色雨衣。手机消息写“到家了吗？”，每镜保存景别和时长。

共用外观说明有助于约束创作，但不能保证各镜人物造型一致。模型可能漏画动作或产生不自然肢体，保存成功只表示文档合法并已持久化。

## 语音与镜头管理

点击输入框左侧麦克风或按 Alt+V，授权后说一条需求。最终转写会自动提交；执行和播报时暂停识别，完成后恢复监听。点击麦克风或说“关闭麦克风”结束。语音不可用时可直接打字。

| 目的 | 例子或按钮 |
| --- | --- |
| 创建与切换项目 | 左侧“＋”新建，下拉框切换。当前页面会记住各项目尚未发送的指令草稿，点击项目名可改名 |
| 增加镜头 | “新建两个镜头”；或点击“＋ 镜头” |
| 切换与排序 | “切换到第二个镜头”“把第三个镜头移到第一位” |
| 命名与复制 | “当前镜头改名为雨夜归途”“复制当前镜头” |
| 修改画面 | “只把雨衣改成红色，保留人物姿态与背景” |
| 删除 | 选中镜头后点“删除”并确认，或说“删除第二个镜头”并按助手提示确认 |
| 检查画面 | “检查手是否握住杯柄，先指出偏差，不要重画” |

直接按钮不请求模型；自然语言交给 Agent 处理。新项目已有一个空镜头，按钮新增两个会再增加两个；完整创作需求由 Agent 判断是否复用空镜头。每项目最多40镜，单次新增最多12镜。当前任务绘图预算最多8次，较长故事需要分批完成。

## 默认画风

工作台右上角点“画风”，输入常用的色彩、线条或构图习惯，再点“保存默认”。同一浏览器访问同一服务时，新建项目和刷新后都能继续使用。可在同一入口修改或清除，设置只在当前浏览器保存。

新画面按本次明确要求、项目共用设定、默认画风的顺序处理。比如默认是暖色手绘，本次指定黑白线稿，助手按黑白线稿绘制。默认值仍保留，已画好的镜头在局部编辑时沿用原画风。

## 直接编辑文字

选择已有画面，在画布下方点击“编辑文字”，从列表选择对白、字幕、招牌或手机消息。修改内容、字号和换行宽度后检查即时预览，再点击“应用改字”。保存不请求模型，形成独立画面版本。

宽屏把画面预览和编辑表单并排显示，窄屏把预览放在表单上方。“还原预览”和“应用改字”固定在表单底部，字段可在面板内滚动。

未保存的草稿会阻止切换文字、镜头和项目，也会暂停其他指令和导出。点击“应用改字”保存，点击“还原预览”重置，或在关闭编辑面板时确认舍弃。检测到超出画布、矩形底板或明显文字重叠时，保存按钮禁用，可以继续调整内容、字号与宽度。

普通 SVG text 和同样式多行文本可直接编辑。共享定义、特殊字符定位、混合样式等复杂结构会显示不可编辑原因，可改用自然语言修改。当前不支持拖动文字、任意气泡自动扩容或跨设备字体一致性保证；保存前仍需看预览。

## 看图检查与修正

Agent 可以调用 `render_shot` 获取真实 PNG，也可以直接用 `review_shot` 对照镜头要求评审。评审自动获取当前版本图片，不需要用户指定工具顺序。是否检查、是否改画由 Agent 根据需求和结果决定。

创作助手中的预览与评审记录可以展开查看。旧版本诊断会标为历史，不能代表改画后的结果。模型评审可能看错，且本次真实递杯实验中一次修正未达标；遇到未修好的动作可保留当前版本、撤销，或缩小修改目标。对照图见[视觉工具实测](experiments/shot-visual-tools-20261117/README.md)。

## 保存、恢复与导出

- 成功修改保存在后端 SQLite；刷新根据 URL 中的 `board` 或浏览器最近项目记录恢复。请保留数据库，浏览器记录不是备份。
- “撤销”或 Ctrl+Z 针对当前画面；Ctrl+Shift+Z 重做。“撤销分镜操作”针对新增、删除、排序和命名。两种历史互不代替。
- 画面保留最多40个版本，结构保留最近100个快照。删除镜头可通过结构撤销恢复；超出历史窗口后不保证能从界面恢复。
- 页面刷新只查询现有任务，不重新提交付费请求。服务重启会把运行中任务标为中断；检查已保存结果后再输入继续需求。
- 多页面修改发生冲突时会同步最新版本，不自动重试绘图。不要在另一个页面反复发送相同需求。
- PNG 为1280×720，SVG 保持自包含矢量文档。整组导出是逐文件下载，没有视频、分镜长图、ZIP 或拍摄说明文件打包功能。
- 顶部“导入”可把 1 MB 以内的 1280×720 自包含 SVG 加到当前项目。只有一个初始空镜头时会替换该占位，新镜头中的文字仍可编辑。可用“撤销分镜”撤回导入。PNG 用于查看和分享。

## 遇到问题

| 现象 | 处理 |
| --- | --- |
| 输入后很久没完成 | 查看助手进展；复杂故事包含多轮决策和绘制，单镜耗时不能代表整组耗时。不要重复提交 |
| 保存了但没有达到要求 | 查看实际画面和未完成项；指出具体对象、动作或接触关系，必要时撤销 |
| 文字放不下 | 缩短内容、调整字号与宽度，或先扩大底板；不强行覆盖保存 |
| 语音不可用 | 使用支持中文识别的 Chrome/Edge，通过 localhost 或 HTTPS 访问，并检查麦克风权限；可以改用文字 |
| 连接或模型错误 | 检查[部署指南的排查步骤](DEPLOYMENT.md#故障排查)，失败时已有画面保留 |
| 项目链接失效 | 点击“打开可用项目”载入最近项目。如果后端没有可用的记录，会创建空白项目 |
