# VoiceCanvas 语音指令语料

> 本文档记录 MVP 阶段需要优先支持的中文语音指令示例，以及建议映射到的结构化语义。后续实现 AI Orchestrator、单元测试和 Demo 脚本时，应优先覆盖本文档中的语料。

## 与技术架构的关系

VoiceCanvas 不设计规则解析主路径。实际运行时，用户输入统一进入 AI Orchestrator，由 AI 根据上下文输出 `EXECUTE_COMMANDS`、`CALL_TOOL`、`ASK_CLARIFICATION` 或 `RESPOND`。

本文档中的“建议解析”用于语料标注、测试断言和 Prompt 示例，不代表系统会通过关键词规则直接执行。实现时应将这些语义转换为可校验的 `AIAction` 和 `CanvasCommand`。

## 语料标注通用格式

建议语料标注使用如下结构：

```ts
{
  intent: string;
  target?: {
    scope?: "project" | "canvas" | "shot" | "element" | "layer";
    shotIndex?: number;
    elementName?: string;
    elementId?: string;
  };
  payload?: Record<string, unknown>;
  confidence: number;
  needConfirm?: boolean;
}
```

字段说明：

- `intent`：指令意图，例如 `create_storyboard`、`add_element`、`update_element`。
- `target`：指令作用对象，例如当前画布、第二镜头、标题元素。
- `payload`：具体参数，例如颜色、位置、文本、数量、风格。
- `confidence`：解析置信度，低于阈值时进入确认流程。
- `needConfirm`：是否需要用户确认。

## 1. 创建项目/分镜

### 创建自由画布

示例句：

- 新建一个空白画布。
- 创建一个自由创作画布。
- 我想先画一张单独的草图。
- 开始一个新的画面。

建议解析：

```json
{
  "intent": "create_canvas",
  "payload": {
    "mode": "free"
  },
  "confidence": 0.95
}
```

### 创建分镜

示例句：

- 创建一个三镜头分镜。
- 帮我做一个五个镜头的短视频分镜。
- 新建一个带货视频分镜。
- 做一个关于新品奶茶的三镜头分镜。

建议解析：

```json
{
  "intent": "create_storyboard",
  "payload": {
    "shotCount": 3,
    "topic": "新品奶茶",
    "sceneType": "sales"
  },
  "confidence": 0.92
}
```

### 根据主题生成初始内容

示例句：

- 创建一个三镜头的珍珠奶茶带货分镜，主打低糖和新品上市。

- 做一个咖啡店探店分镜，风格清爽一点。

建议解析：


## 容错与确认语料

### 指代不明确

示例句：

- 把它放大一点。
- 删除那个。
- 改成红色。
- 移到右边。

处理策略：

- 如果最近操作对象明确，默认作用于最近元素。
- 如果存在多个候选元素，要求用户确认。

建议解析：

```json
{
  "intent": "update_element",
  "target": {
    "scope": "element"
  },
  "payload": {
    "property": "scale",
    "operation": "increase"
  },
  "confidence": 0.62,
  "needConfirm": true
}
```

### 确认与取消

示例句：

- 对，就是这个。
- 不是，改第二个。
- 取消。
- 算了，不改了。

建议解析：

```json
{
  "intent": "confirm_action",
  "payload": {
    "confirmed": true
  },
  "confidence": 0.97
}
```
